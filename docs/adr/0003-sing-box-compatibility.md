# ADR-0003: sing-box 版本兼容策略

- 状态：proposed
- 日期：2026-08-25

## 已落地事实

- Linux amd64 构建内嵌 sing-box `1.13.16` 作为初始版本。
- 托管更新只接受官方稳定 Release 的精确平台资产，校验摘要、归档边界和版本输出，并
  保留上一版本用于回滚。
- 外部核心模式接受绝对可执行文件；生成配置在保存和应用前通过该核心的 `check`。

这些机制解决了下载完整性和原子切换，但没有定义“项目支持哪些 sing-box 版本”。成功
执行 `version` 或 `check` 也不能证明全部热切换、Clash API、DNS、链式代理和通道能力
均兼容。

## 待决定

1. 最低支持版本，以及是否只支持一个 minor 系列。
2. 以版本范围、启动时能力探测还是两者结合进行功能门控。
3. 外部核心不兼容时是拒绝启动、降级功能，还是只在应用配置时报错。
4. 托管更新切换前需要通过哪些代表性配置和管理 API 冒烟检查。
5. 发布流程维护哪些核心版本的自动化兼容矩阵。

在该 ADR accepted 前，文档只能保证内嵌种子版本经过项目测试；“更新到任意最新稳定版”
表示下载与安装能力，不等于所有项目功能均受支持。
